# X Viral Monitor — 実機確認で判明した仕様・未対応事項

- 記録日：2026-11-05（JST）
- 対象：`sysCat64/x-viral-monitor-syscat` の `ja-fix` ブランチ、および本家 `Icy-Cat/x-viral-monitor`
- 位置づけ：I18N-001（ブックマーク挿入機能の多言語化）の実機確認に伴う観察メモ。新しい修正の実施を指示する文書ではない。

## 1. 言語切り替えの観察

**実機での観察**：拡張機能の言語を切り替えたとき、ブックマーク挿入ダイアログ内の表示は変わるが、ダイアログ以外の一部表示はその場では切り替わらない。

**ソース確認で分かったこと**：`bridge.js` は言語設定を含む `XVM_SETTINGS_UPDATE` を送る。今回の I18N-001 では、ブックマーク挿入ダイアログ、バッジ、設定ボタンの再翻訳処理を追加した。一方、既に生成済みの全 UI を一括で再翻訳する共通機構はない。

**評価**：I18N-001 の失敗を意味するものではなく、既存の言語更新方式に由来する制約の可能性が高い。再現する表示箇所やページ再読み込み後の状態は、今後必要なら別途調査する。

## 2. ブックマークフォルダー管理の機能不足

**実機での観察**：拡張機能のブックマークフォルダー選択ポップアップから新規フォルダーを作れるが、作成後にフォルダー名を変更する操作、フォルダー自体を削除する操作が見当たらない。

**ソース確認**：`bookmark-menu.js` に次の処理がある。

| 操作 | 実装状況 |
| --- | --- |
| フォルダー一覧取得 | あり |
| フォルダー新規作成 | あり（`createBookmarkFolder`） |
| 投稿をフォルダーへ追加 | あり（`bookmarkTweetToFolder`） |
| 投稿をフォルダーから除外 | あり（`removeTweetFromBookmarkFolder`） |
| フォルダー名の変更 | 当該ポップアップに実装なし |
| フォルダー自体の削除 | 当該ポップアップに実装なし |

**評価**：現段階では「機能未実装」と整理する。「仕様漏れ」か意図的な対象外かは、本家の設計意図を確認できていないため断定しない。投稿をフォルダーから除外することと、フォルダー自体の削除は別操作である。

## 4. 今回の作業との切り分けと保留方針

- I18N-001 の目的はブックマーク挿入機能の **表示文字列の3言語対応**。フォルダー管理機能の拡張は対象外。
- I18N-001 はテスト39ファイル・728件PASS、Communityビルド成功、`git diff --check`成功との作業報告あり。実機でも日本語表示は概ね問題なしとの観察。
- **現時点では、フォルダー名変更・削除の実装を保留**。必要性が高まった場合、別 Issue で仕様検討する。
- 将来検討する場合は、X 側の利用可能な操作／API、削除確認、キャッシュ整合性、エラーハンドリング、権限・プレミアム要件を先に調査する。
- I18N-001 のコミット・プッシュと、未翻訳 UI の最終残存監査は別の作業として進める。
